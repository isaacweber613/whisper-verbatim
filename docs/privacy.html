Privacy Policy

Last updated: November 2026

Word for Word is an Android dictation app that records speech, transcribes it, and inserts the result into text fields across apps.

What happens to your recording

When you tap the floating button, the app records audio from the microphone until you tap again. The recording goes to the cloud speech-to-text model you picked, through OpenRouter, using the OpenRouter API key you entered.

In the Play Store build, if you have not entered a key, the recording goes to Word for Word's server (a Cloudflare Worker), which passes it to OpenRouter and counts your free minutes. The server does not keep the recording.

In the GitHub builds, when Yiddish is selected, holding the mic button or using the Yiddish shortcut sends that recording to a Yiddish speech model on the developer's PC, through a Cloudflare Worker. The recording and the model's text are kept on that PC to improve the Yiddish model. A random install id and the app version go with the take; they are not linked to your name. If the PC is off, the normal cloud model is used. The Play Store build does not use the developer's PC; Yiddish there uses the normal cloud model.

API keys

Your OpenRouter API key is stored locally on your device in the app's private storage. It is used only to authenticate requests to OpenRouter.

The Play Store build also has a small Word for Word server for free minutes. It does not receive your key.

Accessibility Service

Word for Word uses Android's Accessibility Service to find the focused text field and insert dictated text. After a Yiddish take, it also watches that one text box for your edits, so it can send the corrected words back as the take's correct text.

  • It does not monitor your browsing.
  • It does not collect screen content for analytics.
  • It does not perform background automation or keylogging.

History and usage data

Transcriptions are kept in the app's private history for 24 hours by default, or longer if you turn that on. You can delete them at any time.

The app sends anonymous usage counts to PostHog, an analytics service, unless you turn off "Share usage data". The counts include the app version, Android version, phone make and model, a random install id, and events such as a recording starting or a transcription failing. PostHog never receives your recordings, your words, your history, or your API key.

Data collection

Word for Word has no accounts, no ads, and no crash reporting. The developer does not receive your recordings, your text, or your API key, except for Yiddish takes described above.

Open source

Word for Word is open source, based on Phone Whisper. You can read the code at github.com/isaacweber613/whisper-verbatim.

Contact

For privacy questions, open an issue at github.com/isaacweber613/whisper-verbatim/issues.
