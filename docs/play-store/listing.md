# Play Store listing draft

Prepared November 10, 2026. Copy is a draft, not a submitted listing.

## App name

Word for Word

## Short description

Speak into any text box. Keep your keyboard and choose your speech model.

## Full description

Dictate without switching keyboards. Tap Word for Word's floating microphone button, speak, and tap again. Your words appear at the cursor in the text box you are using. Transcription accuracy depends on the speech model, language, and recording.

The microphone button appears while your keyboard is open. You can also set a key or key combination to start and stop recording on a physical keyboard or keypad.

Choose a speech model through OpenRouter and select a language, or let the model detect it. Verbatim mode asks supported models to keep fillers, repeats, and false starts. With Verbatim mode off, supported models clean them up.

The Play Store build includes 30 free transcription minutes per phone each month. You can enter your own OpenRouter API key to use your own account. Internet access is required. Paid plans are not available in the app.

Transcriptions stay in your phone's history for 24 hours by default. You can keep them longer or delete them. If an app does not allow text insertion, Word for Word copies the transcription so you can paste it.

Yiddish speakers can select Yiddish and hold the microphone button, or use a separate Yiddish shortcut, to try the developer's Yiddish speech model. These recordings, model output, and subsequent corrections from that text box are sent to the developer's computer and retained to improve the model. If that computer is unavailable, the app falls back to the normal cloud model. A quick tap uses the normal cloud model with automatic language detection.

Word for Word uses Android's AccessibilityService API to show the microphone button, find the focused text box, and insert dictated text. It also detects your optional keyboard shortcut. After a Yiddish take, it watches that text box for corrections sent back for training. You choose whether to enable the service.

Anonymous usage counts help identify errors. You can turn them off in Settings under Share usage data. Analytics do not include your audio, dictated words, history, or API key.

Word for Word runs on Android 6 and newer and is open source.
